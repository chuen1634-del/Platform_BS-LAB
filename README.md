# 신규 사업 사전 분석 MVP

신규 사업 담당자가 고객 접점 이전에 회사소개서와 기본 정보로 고객사 사전 분석을 시작하는 내부용 MVP입니다.

## 실행

정적 파일 서버로 실행합니다.

```powershell
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 테스트

```powershell
npm test
```

현재 포함 범위는 프로젝트 생성, 프로젝트별 복수 고객사 관리, 고객사 선택, 고객사별 자료 등록과 즉시 분석, 현장 메모 기반 As-Is/To-Be 업무 구조화, ROI 계산, PoC 범위·성공 기준 저장, 재고·생산 연계 플랫폼입니다.

재고 플랫폼에서는 시스템 안에서 품목, 재고거래, 생산계획, BOM, 공급사 발주, 입고를 입력할 수 있습니다. 입력 즉시 거래 기반 현재고, BOM 기반 자재소요량, 발주잔량, 순부족량, 발주위험을 고객사별로 자동 계산합니다. Excel은 핵심 입력이 아니라 초기 마이그레이션·대량 입력·결과 내보내기용 보조 기능으로 확장할 예정입니다.
