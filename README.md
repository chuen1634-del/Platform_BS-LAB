# 신규 사업 사전 분석 MVP

신규 사업 담당자가 고객 접점 이전에 회사소개서와 기본 정보로 고객사 사전 분석을 시작하는 내부용 MVP입니다.

## 실행

정적 파일 서버로 실행합니다.

```powershell
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 테스트

```powershell
npm test
```

현재 포함 범위는 프로젝트 생성, 프로젝트별 복수 고객사 관리, 고객사 선택, 고객사별 자료 등록과 즉시 분석, 현장 메모 기반 As-Is/To-Be 업무 구조화, ROI 계산, PoC 범위·성공 기준 저장, 사실·추정·확인 필요·제안 구분, 후속 확인 질문입니다. 제안서 자동 생성은 다음 단계입니다.
