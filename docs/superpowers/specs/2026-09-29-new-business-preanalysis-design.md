# 신규 사업 사전 분석 MVP 설계

## 목표

신규 사업 담당자가 고객 접점이 없거나 제한된 상황에서도 회사소개서와 공개자료를 바탕으로 고객사 사전 분석 프로젝트를 만들고, 검증이 필요한 가설과 후속 미팅 질문을 정리할 수 있도록 한다.

## 범위

이번 MVP는 사전 분석 모드만 포함한다.

- 사업개발 프로젝트 생성 및 목록 확인
- 고객사 기본 정보 입력
- 회사소개서 등 파일 업로드 또는 텍스트 입력
- 자료 출처와 분석 기준일 기록
- 회사 개요, 업종 특성, 예상 업무, 예상 Pain Point 생성
- 사실·추정·확인 필요 항목 구분
- 후속 미팅 질문 생성 및 저장
- 분석 결과를 프로젝트 단위로 재확인

다음 기능은 후속 범위로 둔다.

- 미팅 기록 분석
- 현장 방문 진단
- As-Is/To-Be 도면 자동 생성
- ROI 계산 및 PoC 정의
- 제안서·솔루션 구조도 자동 생성
- 외부 사용자, 과금, 권한 관리

## 사용자

주 사용자는 사내 신규 사업 담당자다. 영업, 컨설턴트, 개발자는 MVP에서 결과를 열람하거나 검토하는 보조 사용자로만 고려한다.

## 핵심 흐름

`프로젝트 생성 → 고객 정보 입력 → 자료 등록 → 사전 분석 실행 → 사실/가설 확인 → 미팅 질문 검토`

## 신뢰도 원칙

자료에서 직접 확인되는 내용과 시스템이 추론한 내용을 분리한다. 모든 분석 항목은 출처 유형과 상태를 가진다.

- 상태: `확인됨`, `추정`, `확인 필요`
- 출처 유형: `회사소개서`, `공개자료`, `담당자 입력`
- 분석 결과는 제안 근거가 아니라 사전 검토용 가설로 표시한다.

## MVP 성공 기준

- 신규 사업 담당자가 한 프로젝트를 생성하고 회사소개서 자료를 등록할 수 있다.
- 분석 결과에서 회사 개요, 업종 특성, 예상 Pain Point, 확인 질문을 한 화면에서 확인할 수 있다.
- 추정 결과가 확인된 사실처럼 표시되지 않는다.
- 프로젝트를 다시 열었을 때 입력자료와 분석 결과가 유지된다.
