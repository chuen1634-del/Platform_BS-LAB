# 고객 분석 기반 재고관리 Solution 제안 플랫폼 설계

## 목표

기존 고객사 기반 신규 사업개발 분석 기능과 재고·생산관리 플랫폼을 하나의 고객사 업무 흐름으로 연결한다. 사용자는 고객 정보를 분석하고, 재고·생산 데이터를 입력·계산한 뒤, 그 결과를 근거로 재고관리 Solution 제안서·ROI·PoC를 구성한다.

## 핵심 사용자 흐름

```text
프로젝트 선택
 → 고객사 선택
 → 고객 분석 자료 등록
 → 재고·생산 데이터 입력
 → 재고 문제 및 운영 Pain Point 확인
 → As-Is / To-Be 구조화
 → Solution 구성
 → ROI·PoC 정의
 → 제안서 미리보기
```

## 통합 데이터 원칙

- 프로젝트 안에는 여러 고객사가 존재한다.
- 모든 데이터는 `projectId`와 `customerId`에 귀속된다.
- 기존 분석 결과는 유지하고 재고 운영 결과를 추가 근거로 연결한다.
- 재고 계산 결과를 확인된 고객 사실로 위장하지 않는다.
- 재고 시스템에서 직접 계산된 결과는 `운영 데이터`, 고객 자료에서 나온 내용은 `고객 근거`, 시스템이 해석한 내용은 `추정`으로 구분한다.

## 고객사 화면

고객사 선택 후 동일한 고객사 컨텍스트에서 다음 탭 또는 영역을 제공한다.

```text
사업개발 분석 | 재고·생산 플랫폼 | Solution 제안서
```

### 사업개발 분석

기존 기능을 유지한다.

- 회사소개서·공개자료·미팅·현장메모
- 고객사 개요
- 업종·예상업무
- Pain Point
- 확인됨·추정·확인 필요
- 후속 질문

### 재고·생산 플랫폼

기존 구현 기능을 확장·연결한다.

- 품목·재고거래
- 생산계획·출하계획
- BOM
- 발주·입고
- 현재고
- 부품 필요량
- 발주잔량
- 순부족량
- 생산중단 위험

### Solution 제안서

고객 분석 결과와 운영 계산 결과를 근거로 다음 내용을 표시한다.

- 고객사 개요
- 재고·생산 업무 흐름
- 확인된 문제와 데이터 근거
- As-Is
- To-Be
- 제안 Solution 구성
- 기대효과
- ROI
- PoC 범위·성공기준
- 도입 로드맵

## 자동 연결 규칙

### 운영 데이터 기반 Pain Point

예를 들어 다음 조건이면 운영 근거 카드를 생성한다.

```text
순부족량 > 0
 → 생산계획 대비 자재 부족 위험

현재고 <= 재발주점
 → 발주 판단 지연 또는 안전재고 위험

입고예정일 > 생산일
 → 생산중단 가능성
```

자동 생성 결과는 `추정` 또는 `운영 데이터`로 표시하고, 담당자가 확인된 문제로 확정할 수 있도록 한다.

### As-Is / To-Be

- As-Is: 현재 고객 자료와 입력된 재고 운영 데이터 기반
- To-Be: 재고·생산·BOM·발주·입고를 연결한 목표 업무
- 기대 변화: 부족 사전 파악, 수기 계산 감소, 재고 정확도 개선

### ROI

재고관리 플랫폼의 KPI와 기존 ROI 입력값을 결합한다.

```text
연간 효과
= 재고절감액
+ 긴급구매절감액
+ 특급운송비절감액
+ 수기처리절감액
+ 생산중단손실감소액
```

입력되지 않은 금액은 임의 계산하지 않고 `추가 입력 필요`로 표시한다.

### PoC

운영 데이터가 있는 고객사는 다음 기본 템플릿을 제안한다.

- 대상: 1개 공장 또는 1개 생산라인
- 대상 품목: 주요 부품 10~20개
- 기간: 4~8주
- 성공기준: 재고 정확도, 부족 사전탐지율, 수기처리시간, 긴급발주 감소율

## 제안서 미리보기

제안서 화면은 저장된 내용을 문서형으로 재배열한다. 자동 생성 내용은 근거 출처와 상태를 함께 표시하며, 담당자가 문구를 수정할 수 있는 MVP 편집 영역을 둔다.

## 오류·빈 상태

- 분석 자료가 없으면 고객 확인 필요 상태를 표시한다.
- 재고 데이터가 없으면 운영 근거를 생성하지 않는다.
- 생산계획 또는 BOM이 없으면 자재소요 계산을 하지 않는다.
- ROI 값이 부족하면 숫자 대신 입력 필요 상태를 표시한다.
- 고객사를 변경하면 분석·재고·제안서가 모두 선택 고객사 기준으로 다시 계산·표시된다.

## 구현 순서

1. 고객사별 통합 제안 데이터 계산 모듈
2. 운영 데이터 기반 Pain Point·As-Is/To-Be 생성
3. 고객사 화면 탭과 제안서 화면
4. ROI·PoC 자동 연결
5. 제안서 미리보기 및 내보내기

## 제외 범위

- 외부 ERP/MES/WMS 실시간 연계
- 실제 발주 전송
- 외부 고객 로그인 및 권한
- AI 문장 생성 API 연동
- 정식 PDF/PPT 파일 생성
